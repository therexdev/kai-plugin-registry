# KAI Plugin Registry 0.1.0

- Initial signed catalog of eleven official KAI Core plugins, including Koinos Node and Remote Access.
- Publisher keys, exact signed package hashes, immutable release URLs, permissions, and minimum Core versions pinned for every entry.
- Explicit registry refresh and permission-reviewed installation in KAI Core 0.3.0, with bounded downloads, signature verification, expiry checks, and persistent rollback protection.
- Community submission workflow for plugins hosted in developers' own GitHub repositories. Submitted code and dependency hooks are never executed by the verifier.

The registry is a catalog rather than a separately installed feature plugin. Paid Agent Network rentals and other deferred features remain described in the individual plugin release notes. Refreshing this registry does not update or run installed plugins automatically.
