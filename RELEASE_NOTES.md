# KAI Foundation plugin catalog 0.3.9

Updates Brain to **0.3.2**, Connections to **0.3.3**, Workflows to **0.3.2**, Agent Network to **0.3.1**, and Koinos Code to **0.3.2**.

Brain and Connections remove excess left padding. All four workspace sidebars use the same compact layout and polished, brand-matched buttons, including responsive navigation in smaller windows.

Koinos Code fixes a stalled response when the model takes time to begin answering. Planning and tool activity now show progress, and Stop cancels an outstanding read. File and command approvals remain required. Koinos Code requires Core **0.7.9** or newer; **KAI Core Beta 0.7.11** also retains and refreshes Earn and Network figures across navigation.

Catalog sequence 14 updates these five signed packages and retains the other seven entries unchanged. The archived legacy registry.json remains unchanged. Refreshing the catalog does not install updates or alter saved plugin data.
